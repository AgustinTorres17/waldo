# Changelog

## 0.1.0

First public release. Waldo runs on your Mac: no account, no servers, no subscription.

### Writing, in any app

- Correct and translate selected text in 9 languages, and review every change before replacing it.
- Rephrase text to say the same thing better.
- Hotkeys for every action, and undo for the last replacement.
- A popup on selected text, with opt-in support for Chromium browsers.

### Make it yours

- Modes for how you want to sound, with a mode and a language per app.
- A glossary for the words that must stay as they are.
- Three themes: Glass, Mono and Editorial.

### Chat

- A chat window with saved history, kept on your Mac.
- Ask about selected text, a region of the screen or the whole screen.
- Add images from a file or by pasting them.
- Optional web search through DuckDuckGo or your own SearXNG server.

### Models

- Qwen3.5 4B and 2B running locally with llama.cpp.
- Apple Intelligence on macOS 26, where available.
